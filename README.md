# rglodzinski/tap

Homebrew tap for [Limpa Tudo](https://github.com/rglodzinski/LimpaTudo) — the safe, open-source disk cleaner for macOS & Linux.

```bash
brew tap rglodzinski/tap
brew trust --cask rglodzinski/tap/limpa-tudo   # Homebrew 7+ asks you to trust third-party casks
brew install --cask limpa-tudo
```

The cask is maintained in the main repository under `packaging/homebrew/`.
